# 溯数 TraceNum

**可溯源的年报查数工具。** 用自然语言问年报里的一个数，答案里的每个数字都能点开，直接翻到年报 PDF 原页并用荧光笔标出；找不到可核验的证据时拒答，不编数。查到的数可以一键加入底稿，导出带页码和核验状态的 Excel。

| | |
|---|---|
| 在线体验 | *上线后填写*（公开页可看 5 道精选题的真实运行回放；自由提问对专属链接开放） |
| 90 秒演示 | *录制后填写* |
| 论文实验回放 | [xpiw-1.github.io/financerag-workbench](https://xpiw-1.github.io/financerag-workbench/)：20 道正式题 × 3 种策略、60 条正式运行逐条回放 |

## 评测结果（课程论文，冻结配置 + 匿名盲评）

语料为比亚迪、威胜信息 2025 年年报。20 道正式题，每题跑 3 种策略，共 60 次运行，揭盲前不看策略标签。

| 策略 | 做法 | 准确率 | 相对单轮的 token 代价 |
|---|---|---|---|
| S1 单轮 | 检索一次、回答一次 | 45%（9/20） | 1× |
| S2 固定两轮 | 无论核验结果都检索两轮 | 60%（12/20） | 2.8× |
| **S3 自适应** | 每轮规则核验后判断是否续检，最多三轮 | **80%（16/20）**，引用支持率 94.7% | 4.3× |

主要错误来源是**证据没被召回**，不是计算错误。溯数默认使用 S3。完整数字见站内“实验设计”页和论文回放站。

## 架构

```
浏览器 ──> Caddy（自动 HTTPS）
             ├─ <个人域名>              作品集首页（Astro 静态页）
             └─ tracenum.<个人域名>
                  ├─ 静态站（React + Vite）  精选题回放、PDF、底稿导出，不依赖后端
                  └─ /api/* ──> FastAPI（Docker，单进程）
                                 ├─ 访问码会话 → 每日限额 → 并发 1 → 月度费用硬闸
                                 └─ pipeline.py：调用论文冻结的 LangGraph 节点（v2/，只读）
                                       ├─ 向量检索  bge-base-zh-v1.5（服务器 CPU）+ Chroma
                                       ├─ 重排      bge-reranker-v2-m3（托管 API，与论文同一模型）
                                       └─ 生成      DeepSeek（deepseek-flash）
```

- **冻结代码不改一个字节。** `deploy/assets.lock.json` 锁定运行所需的 40 个冻结文件（68 MB）及其哈希，由一次真实运行的文件访问追踪得出（`scripts/trace_runtime_assets.py`）。打包时唯一派生的文件是数据清单：把两条 Windows 本地 PDF 路径换成容器路径，脚本断言其他字段完全不变。
- **公开与实时分离。** 公开访客看到的是预先运行的真实结果，页面标明录制时间；实时提问只对专属链接开放，只跑 S3。
- **花钱有上限。** 每次提问前按最坏情况预占费用（39,000 tokens 全按输出价计），结束后按 DeepSeek 返回的用量结算；用量未知时保留预占。月度超额即停，退回精选题。

## 已知局限（如实说明）

- **语料缺陷**：比亚迪年报第 137 页（母公司现金流量表）在冻结语料中被标成第 130 页合并现金流量表的续页，涉及现金流的题会引用错页。这个缺陷保留在冻结语料中，没有选作精选题。
- **结果有随机性**：DeepSeek 在温度为 0 时也不完全确定，同一道题再跑一次，轮次和答案都可能与论文记录不同。
- **模型服务端会变化**：论文正式运行时 DeepSeek 返回的 `system_fingerprint` 是 `e72d3c7f…`，2026-11-11 起溯数的运行都返回 `bc19ba97…`（模型别名未变）。精选题的录制就在新指纹下完成；线上页面会显示当前指纹是否与论文一致。
- **重排改为托管 API**：服务器只有 2 核 CPU，本地重排每轮约 30 秒，线上改为调用托管的同一模型（BAAI/bge-reranker-v2-m3）。`scripts/compare_rerank.py` 把 98 轮检索的同一批候选重新送去打分：76.5% 的轮次前 5 名顺序与论文本地分数完全一致；其余 23 轮的差异都出现在本地分数几乎并列（相差小于 0.01）的位置，其中 18 轮只是前 5 名内部换位。这没有达到原定的"全部一致"，作者在看过数据后决定接受，放行规则改为端到端不劣于本地：精选题上托管重排答错的题，论文本地重排同样答错（`scripts/accept_rerank.py`，结果存档于 `deploy/validation/`）。
- **WSI-2025-008 近期不稳定**：这道精选题的录制（2026-11-11）1 轮答对 22%；2026-11-18/19 用同样配置重跑，无论托管重排还是论文本地重排，模型都在三轮后拒答。第 1 轮选中的证据与此前完全相同，差异来自生成侧。页面上已注明。

## 本地运行

需要论文实验仓库的冻结管线（`../v2`）。公开仓库里的前端可以单独运行：

```powershell
cd web
npm install
npm run dev            # http://127.0.0.1:5180 —— 没有后端时即公开演示模式
```

完整后端（在实验项目根目录下）：

```powershell
conda activate finance-rag
cd tracenum\backend
$env:TRACENUM_DEV = "1"            # 本地工作台：三策略实时对照、录制管理
python -m uvicorn server:app --port 8765
```

测试：`python -m unittest discover -s tests -v`（`test_api_live` 需要冻结资产，CI 只跑 `test_live_guard`）。

## 部署

```powershell
python scripts/lock_assets.py --check          # 冻结资产与锁一致
python deploy/package_runtime.py               # 生成 build/runtime（Docker 构建上下文）
```

服务器上的目录结构、Caddy 配置和开关见 `deploy/compose.yaml` 与 `deploy/Caddyfile`。`docker compose stop api` 即关闭实时提问，公开页面不受影响。
